Every fallible xa11y operation returns `Result<T, Error>` in Rust, raises an
exception in Python, and rejects with an error in JavaScript. This page is the
catalogue.

For how to *read* a failure, including the diagnosis attached to timeouts and
selector misses, see
[Errors and diagnosis](/explanation/errors-and-diagnosis/).

## Variants

The Rust `Error` enum is the source of truth. Both bindings collapse some
variants onto a shared class, so the mapping columns are what you catch.

| Rust variant | Raised when | Python | JavaScript |
| --- | --- | --- | --- |
| `PermissionDenied` | Accessibility or Screen Recording permission is not granted. Carries setup instructions. On macOS 26+ both permissions are required. On Windows, also raised by input simulation when the target window is known to belong to a process at a higher integrity level, such as an elevated app, which UIPI would silently drop the input for. | `PermissionDeniedError` | `PermissionDeniedError` |
| `AccessibilityNotEnabled` | The application advertises a tree, but its content is empty because its accessibility bridge is off. Chromium and Electron on Linux without `--force-renderer-accessibility` is the common case. | `AccessibilityNotEnabledError` | `AccessibilityNotEnabledError` |
| `SelectorNotMatched` | No element (or no application) matched the selector on a fail-fast call. Carries a diagnosis. | `SelectorNotMatchedError` | `SelectorNotMatchedError` |
| `ElementStale` | The element's platform handle is stale and re-traversal could not relocate it. | `SelectorNotMatchedError` | `SelectorNotMatchedError` |
| `ActionNotSupported` | The element's role does not support the requested action. | `ActionNotSupportedError` | `ActionNotSupportedError` |
| `TextValueNotSupported` | The platform cannot set a text value on this element. | `ActionNotSupportedError` | `ActionNotSupportedError` |
| `Timeout` | A wait, or the auto-wait inside an action, exceeded its deadline. Always carries a diagnosis. | `TimeoutError` | `TimeoutError` |
| `InvalidSelector` | The selector string could not be parsed. Raised before any platform call. | `InvalidSelectorError` | `InvalidSelectorError` |
| `InvalidActionData` | An action argument failed validation. `select_text()` with `start > end` does this, as does an empty `Text.find()` needle, an unknown text unit name, an uppercase `Char` key, a malformed key name, or a bad target tuple. | `InvalidActionDataError` | `InvalidActionDataError` |
| `InvalidTextRange` | A text range is past the end of the text, reversed, or splits a UTF-16 surrogate pair. Also raised by `Text.bounds()` for a range covering more than 1000 rendered lines. Carries `start`, `end`, and `length`. | `InvalidTextRangeError` (subclass of `InvalidActionDataError`) | `InvalidTextRangeError` (subclass of `InvalidActionDataError`) |
| `InvalidConfig` | Process-wide configuration is invalid, such as an unparsable `XA11Y_DEFAULT_TIMEOUT`. | `ValueError` | `InvalidActionDataError` |
| `NoElementBounds` | The element has no bounds, so no screen point can be computed for it. Off-screen and virtual nodes hit this. | `ValueError` | `InvalidActionDataError` |
| `Unsupported` | No backend covers this operation on the current platform or session. A Linux session with neither `DISPLAY` nor `WAYLAND_DISPLAY` set hits this. | `ActionNotSupportedError` | `ActionNotSupportedError` |
| `Platform` | A raw platform failure. Carries the OS error code and message. | `PlatformError` | `PlatformError` |

Two of the mappings are worth noticing before writing an `except` clause.
`InvalidConfig` and `NoElementBounds` raise a plain `ValueError` in Python
rather than an xa11y class, so `except xa11y.XA11yError` does not catch them.
Every other variant descends from `XA11yError` in Python and from `XA11yError`
in JavaScript.

## Which surfaces raise what

Most variants can come from any call. These are the ones tied to a particular
surface:

| Surface | Variants it raises |
| --- | --- |
| [Input simulation](/guides/input/) | `Unsupported`, `NoElementBounds`, `InvalidActionData`, `Platform`; on Linux, `PermissionDenied` when the `input` group is missing; on Windows, `PermissionDenied` when the target window is known to run at a higher integrity level. macOS cannot report a missing Input Monitoring grant, so it drops the events silently |
| [Screenshots](/guides/screenshots/) | `PermissionDenied` (macOS Screen Recording not granted, or the Wayland portal denied consent), `Unsupported` (no capture backend for the session), `NoElementBounds`, `Platform` (capture or PNG encode failure) |
| [Selectors](/reference/selectors/) | `InvalidSelector` at parse time, `SelectorNotMatched` or `Timeout` at resolve time |
| [Events](/reference/events/) | `Timeout` from `wait_for` |
| [Text by range](/guides/tables-and-text/) | `ActionNotSupported` when the element has no text interface, `InvalidTextRange`, `InvalidActionData`, `ElementStale` from a `Text` bound to an element that went away, `Unsupported` on macOS and Windows and for a text unit the toolkit has no boundaries for |
| [Tables and collections](/guides/tables-and-text/) | `ActionNotSupported` when the element is not a table, cell, or selection container; `Unsupported` on macOS and Windows, and on Linux for table-level headers of a table with more than 1000 columns or rows |

## Structured fields

`Timeout` and `SelectorNotMatched` carry a `Diagnosis` describing what the
operation was waiting for and what it last saw. The fields are reachable
without parsing the message:

| Rust (`Diagnosis`) | Python | JavaScript |
| --- | --- | --- |
| `condition` | `condition` | `condition` |
| `selector` | `selector` | `selector` |
| `last_observed` | `last_observed` | `lastObserved` |
| `hidden_reason` | `hidden_reason` | `hiddenReason` |
| `auto_scroll` | `auto_scroll` | `autoScroll` |
| `candidates` | `candidates` | `candidates` |
| `scope` | `scope` | `scope` |
| `elapsed` (on `Timeout`) | `elapsed` (seconds) | `elapsedMs` |

`InvalidTextRange` carries the refused range instead of a diagnosis. Offsets
are UTF-16 code units:

| Rust (`Error::InvalidTextRange`) | Python (`InvalidTextRangeError`) | JavaScript (`InvalidTextRangeError`) |
| --- | --- | --- |
| `start` | `start` | `start` |
| `end` | `end` | `end` |
| `length`, the text's length when the check knew it | `length`, or `None` | `length`, or `null` |

In Python every attribute is always present, holding `None` or `[]` when it
does not apply, so no `hasattr` guard is needed. On `SelectorNotMatchedError`,
`elapsed` is always `None`.

See [Errors and diagnosis](/explanation/errors-and-diagnosis/) for what each
field contains and how to read one.

## Delivery disposition

Every error says whether a failed action may already have taken effect. The
value is one of two strings:

| Value | Meaning |
| --- | --- |
| `not_delivered` | The action never reached the application, so a retry cannot apply it twice. |
| `unknown` | The action was dispatched and the outcome is unconfirmed. The application may have acted on it. |

A successful action still returns `Result<()>`. The disposition describes
failures only.

| Rust variant | Disposition |
| --- | --- |
| `PermissionDenied`, `AccessibilityNotEnabled`, `SelectorNotMatched`, `ElementStale`, `ActionNotSupported`, `TextValueNotSupported`, `InvalidSelector`, `InvalidActionData`, `InvalidTextRange`, `InvalidConfig`, `NoElementBounds`, `Unsupported` | `not_delivered` |
| `Timeout`, `Platform` | `unknown` |

A `Diagnosis` can override the variant default. The wait and not-found
diagnoses built by `Locator` set `not_delivered`, because the wait expired
before the action was attempted.

| Surface | Where it appears |
| --- | --- |
| Rust | `Error::delivery()` returns a `Delivery`. `Delivery::is_safe_to_retry()` is true for `NotDelivered`. |
| Python | The `delivery` attribute on every exception, always present. |
| JavaScript | The `delivery` property on every error, always present. |
| MCP | A top-level `delivery` field in the failed result of every tool. An `invalid_arguments` failure reads `not_delivered`, because nothing was attempted. |
| CLI | A `delivery:` line on stderr after the error of an action command (`action`, `click`, `move`, `drag`, `scroll`, `key`, `type`), except for a usage error. |

The platform mapping behind `unknown` is in
[Platform details](/reference/platform-details/).
